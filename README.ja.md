# threejs-water

Three.js用のリアルタイム水シミュレーションで、反射、屈折、インタラクティブなカウスティクスを実装しています。このプロジェクトは、Evan Wallace氏による基盤となるデモである[webgl-water](http://madebyevan.com/webgl-water)の移植版です。

**ライブデモ: [https://martinrenou.github.io/threejs-water](https://martinrenou.github.io/threejs-water)**

![タイル張りのプールでのリアルタイム3D水シミュレーション。表面のリアルなカウスティクスと波紋を示しています。](water.png)

## 機能

- **リアルタイム水シミュレーション:** シェーダーベースの物理シミュレーションにより、各フレームで水面の高さと速度を更新します。
- **動的なカウスティクス:** 水面を通じた光の屈折を計算し、リアルなカウスティクスを生成します。
- **インタラクティブな波紋:** マウスで水面を波立たせ、波紋を作ることができます。
- **高品質なレンダリング:** 水面は、スカイボックスの反射とプール底の屈折をフレネル項でブレンドして描画されます。
- **モジュール化されたコードベース:** ロジックは、シミュレーション(`WaterSimulation`)、カウスティクス(`Caustics`)、水面(`Water`)、プール(`Pool`)の各クラスにきれいに分離されています。

## 動作原理

このエフェクトは、マルチパスレンダリングパイプラインによって実現されています:

1. **水シミュレーション:** シミュレーションは完全にGPU上で実行されます。水面の高さと速度を保存するために、2つのレンダーターゲットをピンポン方式で使用します。GLSLシェーダーが前の状態に基づいて波の伝播を計算し、波紋がリアルに広がり、消えていく様子を再現します。
2. **カウスティクス生成:** 水面のメッシュを光源の視点からプールの底に投影します。頂点シェーダーは、水面の法線ベクトル（シミュレーションテクスチャから取得）に基づいて光線を屈折させます。その結果生じる光の集中をカウスティクステクスチャにレンダリングします。
3. **最終シーンのレンダリング:**
    - まずプールのジオメトリがレンダリングされます。シェーダーでタイルテクスチャをサンプリングし、生成したカウスティクステクスチャを適用することで、プールの底に明るい模様を作り出します。
    - 次に、水面（テッセレーションされた `PlaneGeometry`）がレンダリングされます。頂点シェーダーはシミュレーションテクスチャを使用して頂点を垂直に変位させます。フラグメントシェーダーは反射と屈折を計算し、最終的な透明感のある水のエフェクトをレンダリングします。

## セットアップと使用方法

このプロジェクトでは、特定のバージョンのThree.js（r113）とそれに対応する `TrackballControls` を使用しており、これらは `index.html` 内でCDN経由で読み込まれています。

プロジェクトをローカルで実行するには:

1. リポジトリをクローンします:
    ```bash
    git clone https://github.com/martinrenou/threejs-water.git
    ```
2. プロジェクトディレクトリに移動します:
    ```bash
    cd threejs-water
    ```
3. ローカルWebサーバーを起動します。一般的な方法としてPythonを使用します:
    ```bash
    python -m http.server
    ```
4. ウェブブラウザを開き、`http://localhost:8000` にアクセスします。

メインクラスである `WaterSim` がシミュレーションを統括します。
